# Paired-channel synthetic calibration

This study asks whether two sensor outputs can separate *Meloidogyne incognita* J2 density from a varying *Caenorhabditis elegans* L4 background under a fixed, idealized model. All inputs and outcomes are deterministic simulations without measurement noise or independent biological replicates. Channel names identify their intended ligand targets.

## Inputs and signal generation

The ODE starts from the supplied parameters in [channel3.json](inputs/channel3.json) and [channel18.json](inputs/channel18.json), with the [literature reaction core](../pathway/configs/literature_core_source.json). Parameter records contain `value`, `unit`, `status` and `source`; `assumed`, `fitted_synthetic` and `derived_from_assumed_blank` distinguish their scientific bases. The standalone pathway and the paired channels use their respective parameter sets. Parameter meanings and equations are in the [pathway methods](../pathway/README.md#equations-and-conservation).

[scenario.json](inputs/scenario.json) defines species, stages, release rates, collection and readout conditions. [generation-design.json](inputs/generation-design.json) defines target/background mixtures for signal generation. The signal tables contain `ode-endpoints.csv` (generated), `calibration.csv` (generated) and `evaluation.csv` (generated). Calibration and evaluation use distinct sample IDs and target/background combinations. Each target ascr#3:ascr#18 ratio (1:5, 1:10 and 1:20) has 12 evaluation samples. Protocol and sample IDs join these records.

The assumed total release of ascr#3 + ascr#18 is 1 fmol/worm/hour. Target composition is 1:10 and background composition is 10:1; equal release per worm retains the effect of sample abundance. Collection lasts 1 hour into 1 mL from 100 cm3 soil, with complete recovery and no dilution. The channel adapters use `L3=(S3+0.02*S18)/(1 nM)` and `L18=(1.25*S3+S18)/(1 nM)`. The shared six-state ODE is solved with Radau, `rtol=1e-9`, `atol=1e-12`, and read at 8 hours.

The adapter interprets the ODE color state as micromolar betaxanthin equivalent. At 480 nm and 1 cm effective path length, `A480 = 48000 L mol^-1 cm^-1 * 1 cm * C uM * 10^-6 = 0.048 C`. The matched simulated blank is 0.5 uM equivalent (A480 = 0.024). Inputs `x3` and `x18` are blank-corrected A480 in that order.

| Table fields | Meaning and units |
|---|---|
| `sample_id`, `channel`, `split`, `mi_ascr3_to_ascr18` | Sample identity, sensor channel, calibration/evaluation role and target ligand ratio |
| `target`, `target_density_J2_per_100cm3` | Target density, Mi J2/100 cm3 soil |
| `background`, `background_density_L4_per_100cm3` | Background density, Ce L4/100 cm3 soil |
| `ascr3_nM`, `ascr18_nM`, `effective_L` | Ligand concentrations and dimensionless adapter input |
| `ode_pigment_uM` | ODE pigment endpoint in uM equivalent |
| `ode_A480`, `ode_A480_blank_corrected`, `x3`, `x18` | Raw and matched-blank-corrected absorbance |
| `data_origin` | Synthetic ODE output identity |

## Regression and generated outputs

Ordinary least squares fits `density = beta0 + beta3*x3 + beta18*x18`. Coefficient order is intercept, channel 3, channel 18; negative coefficients and predictions are retained. Target units are `J2/100 cm^3 soil`.

Generation and replay below create `model.json`, `summary.json`, `predictions.json` and a comparison figure at runtime. They contain fitted parameters, residual-based uncertainty, full sample identities, all three estimates, range/QC decisions and conditional economic scenarios. Scientific results are on the [signaling Wiki](https://2026.igem.wiki/nku-china/model-ode/).

Calibration and evaluation are distinct mixtures generated by the same ODE. Both ODE configurations, fitted regression coefficients, background composition and common total release stay fixed during the assumed target-ratio comparison.

The formal 95% individual prediction interval uses OLS residual variance, coefficient covariance and a Student t quantile with six degrees of freedom. Its assumptions are independent homoscedastic normal errors and fixed readings. Counting, blank and batch uncertainty are excluded; empirical coverage is unknown for these deterministic data.

The economic adapter uses [eco_model_example_model.json](../../economic-model/configs/eco_model_example_model.json) and the [economic methods](../../economic-model/README.md). Density inputs are J2/100 cm³ soil and monetary outputs are EUR/ha. Reported benefits compare density-guided testing with no testing and uniform treatment. The actual parameters used for all 36 predictions are recorded in `summary.json.economic_parameters`.

## Python input interface

`fit`, `predict` and `eco_scenarios` are available from `src.modeling.dual_channel.calibration`. Each standalone prediction includes its protocol, evidence status, reference basis, calibration range and density unit. The economic interface consumes that complete prediction and returns units with each scenario; shared fields are grouped only when replay serializes the batch.

- Supply paired readings from the same sample extraction in fixed `[x3, x18]` order. Compute `x3 = raw_c3 - blank_c3` and `x18 = raw_c18 - blank_c18` with channel-specific blanks matched for batch, matrix, sensor, timing and instrument settings. Preserve negative corrected readings. A zero-density sample uses an independent matched blank.
- Supply an independent numeric reference density in `J2/100 cm^3 soil`, with unique sample IDs. Use `reference_basis='spike_count'` or `'independent_field_count'`. Density from direct counts is `100 * target_count / soil_volume_cm3`. Aggregate technical repeats within the sample; record the aggregation rule and reference-count basis.
- Numeric zero is a value; an empty field is missing. Reject missing required values, incomplete pairs and unit mismatches before passing inputs to the API.
- Bind species/stage, matrix, sample/extract volumes, dilution, constructs, readout units and timing to `protocol_id`. `fit` requires explicit `evidence_status`; measured inputs use `measured_unvalidated`. Protocol changes require an appropriate calibration.
- `predict` requires explicit boolean `saturated` and `qc_pass`, determined under the measurement protocol. Unknown values are rejected. The simulated replay sets `saturated=False` and `qc_pass=True` as generator assumptions.

Protocol mismatch, saturation, failed/unknown QC, invalid signals, signals outside the joint calibration convex hull, density outside the calibrated 0-120 range and negative density block the economic interface. An interval extending beyond calibration or economic support also blocks it. Physical interval truncation at zero is flagged while the original OLS interval remains intact.

For qualified intervals, the economic adapter evaluates endpoints, point estimate and both sides of every crossed threshold. Band tokens `低`, `中`, `高` mean Low, Medium and High. Crossed thresholds set `grade_uncertain`; outputs describe conditional model scenarios.

## Run

Dependencies are in [dual-channel requirements](../../../environments/dual-channel-requirements.txt). Run from the repository root with new output directories:

```sh
python -m src.modeling.dual_channel.generate_inputs --input-dir studies/signal-model/dual-channel/inputs --source studies/signal-model/pathway/configs/literature_core_source.json --output runs/dual/generated
python -m src.modeling.dual_channel.replay --input-dir runs/dual/generated --output runs/dual/replay --eco-config studies/economic-model/configs/eco_model_example_model.json --protocol-id SIM_V4_MI1TO10_CE10TO1_Q1_8H_A480
```

The generator writes endpoint, calibration and evaluation CSVs plus solver/software/unit information in `generation.json`. Replay writes `model.json`, `summary.json`, `predictions.json` and `dual-channel-check.png`; it reads the generated CSV directory. From another directory, set `PYTHONPATH` to the repository root and use absolute input paths. Set `MPLCONFIGDIR` to a writable cache if needed. Existing output directories and paths inside study inputs/references are refused; failed runs leave no partial final directory.

## Biological basis

The release scenario uses qualitative ascaroside profiles from Manosalva et al. (2015). [scenario.json](inputs/scenario.json) records the separate target/background source locations, assumed composition and absolute release scale, and the target-ligand identification condition. [Choe et al. (2012), Fig. 2](https://pmc.ncbi.nlm.nih.gov/articles/PMC3360977/), studies *M. hapla*, a different species.
